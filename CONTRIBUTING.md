# Contributing

Thanks for your interest in Woosmap Agent Skills.

We don't accept pull requests from outside the Woosmap team. Each skill is
checked against the live Woosmap APIs and docs before release, so we keep
authorship in-house.

You can still help:

- **Report a problem.** Open an [issue](https://github.com/Woosmap/agent-skills/issues)
  if a skill gives wrong guidance, points to an outdated API or class, or
  misses a migration trap. Include the prompt you used and what the agent did.
- **Ask for a skill.** Open an issue describing the Woosmap product or
  workflow you want covered, and why the docs alone aren't enough.
- **Fork it.** The skills are MIT-licensed. Adapt them to your own projects;
  if you build something useful, tell us in an issue.

For questions about Woosmap itself, see the
[developer docs](https://developers.woosmap.com) or contact
[Woosmap support](https://developers.woosmap.com/support/contact/).
